Covers `app/`, `components/`, `hooks/`, `store/`, `theme/`, `constants/`, and `lib/`. Bundled JSON files under `data/` are covered by naming pattern in `03-vocabulary-data.mdx` rather than listed individually.

| File | Purpose | Imports from | Imported by |
| --- | --- | --- | --- |
| `app/layout.tsx` | Root layout - Google Fonts `<link>` for JetBrains Mono, wraps app in `ThemeProvider` | `theme/ThemeContext` | Next.js (root layout) |
| `app/page.tsx` | Home - three module cards + "Continue" resume shortcuts | `components/Pressable`, `components/Scales`, `components/ThemeToggle`, `hooks/useIELTSData`, `store/uiStore`, `theme/*`, `lib/storage` | Next.js (`/`) |
| `app/creators/page.tsx` | Credits screen - links to creators' portfolios and other projects (incl. `want-a-resume`) | `components/NavBar`, `components/Pressable`, `components/Scales`, `theme/*` | Next.js (`/creators`) |
| `app/german/page.tsx` | Deutsch Artikel level picker with per-level accuracy | `hooks/useGermanData`, `hooks/useProgress`, `store/uiStore`, shared chrome components | Next.js (`/german`) |
| `app/german/[level]/page.tsx` | Deutsch Artikel swipe game screen, incl. "Deck complete" state | `components/ArtikelCard`, `components/StatChip`, `hooks/useGermanData`, `hooks/useProgress`, `store/uiStore`, shared chrome components | Next.js (`/german/[level]`) |

## Things worth knowing that don't fit neatly into one page

- **`page.module.css` is dead** - leftover from the `create-next-app` starter, never imported.
- **`framer-motion`'s `motion` import in `LifeCalendar.jsx` is unused** - every animation in the app is plain CSS (`@keyframes`, `transition`), not `framer-motion` components.
- **`LIFE_EXPECTANCY_YEARS` (77) is declared independently in both files** rather than shared from one constants module - they happen to agree, but nothing enforces that they stay in sync if one is ever changed without the other.
- **`Corner` and `BgCanvas` are duplicated verbatim** between `MementoMori.jsx` and `LifeCalendar.jsx`.
- **The calendar's auto-scroll-to-current-week only works on the mobile layout** - see the flagged note in `04-life-calendar.mdx`.

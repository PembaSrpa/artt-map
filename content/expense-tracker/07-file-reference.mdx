## Things worth double-checking

- `render.yaml`'s `startCommand` (`uvicorn main:app`) disagrees with `Procfile`'s (`uvicorn backend.main:app`) - see `01-overview.mdx`.
- `PyMySQL` in `requirements.txt` and `test_connection.py`'s MySQL-specific connectivity check both appear to be leftovers from before this project's move to Postgres/Supabase.
- There's no `PUT /budgets/{id}` route despite `crud.update_budget` being fully implemented - see `03-api-reference.mdx`.
- Three of the six `/visualizations/*` endpoints (`budget-comparison`, `income-expense`, `category-trend`) return a placeholder "coming soon" chart rather than real data - see `05-visualizations-and-exports.mdx`.

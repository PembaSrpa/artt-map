## Notable observations

- **`lib/utils.ts`'s `cn()` isn't used anywhere yet** - every component in this project builds its `className` strings with plain template literals/ternaries instead, unlike most of the other projects documented in `content/`, which do use an equivalent helper throughout.
- **`DocsSidebar` re-fetches `getProjects()`/`getProjectPages()` itself** rather than receiving them as props from `app/docs/[project]/[slug]/page.tsx`, even though the page component already computed the same data one level up (to pass to `MobileSidebar`, which *does* receive them as props). Both reads are cheap local-filesystem calls, so this isn't a performance concern, but it's a small inconsistency in how the two sibling components get their data.
- **`public/`'s five default `create-next-app` SVGs are unused** - see `01-overview.mdx`.

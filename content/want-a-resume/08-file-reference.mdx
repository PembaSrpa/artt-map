## Dependencies present but not currently wired up

- **`react-hook-form`** / **`@hookform/resolvers`** - listed in `package.json`; no form in `src/components/editor/` uses `useForm` or a resolver. Every form here is plain controlled-input state patched straight into the Zustand store instead.
- **`pdfjs-dist`** - listed in `package.json`; not imported anywhere under `src/`. The PDF preview is shown via a plain `<iframe src={blobUrl}>`, not a `pdfjs`-based custom viewer.

> ⚠️ Unclear: both may be leftover from an earlier implementation approach (e.g. a form-validation layer or a custom in-app PDF viewer) that was later simplified to the current controlled-state-plus-`iframe` approach, or may be intended for near-term future use. Neither was confirmed from the code itself.

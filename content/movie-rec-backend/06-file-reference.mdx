## Everything flagged across these pages, in one place

- `GET /api/movies` and `GET /api/books` - the two broken live API routes - see `01-overview.mdx` and `04-api-routes.mdx`.
- `init_database.py`, `seed_production_db.py`, `fetch_and_save_books.py`, and `view_movies.py` all fail immediately on missing functions; `fetch_and_save_movies.py`/`fetch_and_save_books.py` fail only at their final stats-printing step - see `05-broken-setup-and-seed-scripts.mdx`.
- Movie posters and `original_language`, plus book `page_count`/`average_rating`/`ratings_count`, are silently never saved correctly due to field-name mismatches - see `05-broken-setup-and-seed-scripts.mdx`.
- Two independent `declarative_base()` instances exist; only one is actually used - see `01-overview.mdx`.
- `.env.example`'s `TMDB_API_KEY` looks like a real key rather than a placeholder - see `01-overview.mdx`.
- `scikit-learn`, `scipy`, and `alembic` are listed dependencies with no corresponding code in this repository.

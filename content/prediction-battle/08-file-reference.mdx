## Notable cross-project observations

- Both `Pemba/` and `Pranay/` independently reimplement a `run_train.py`/`run_predict.py` CLI pair, a `config.py`, a `features.py`, a `train.py`, and a `predict.py` with the same names and similar responsibilities, but zero shared code between them - see `07-model-comparison.mdx` for how their actual implementations diverge underneath the matching filenames.
- `components/LeaderboardTable.tsx` in `App/` is dead code in the sense that nothing imports it, but it's not obviously safe to delete - see the "unfinished feature" note in `03-frontend-components.mdx` and `04-scoring-and-leaderboard.mdx`.

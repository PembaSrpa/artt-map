## Everything flagged across these pages, in one place

- All four Subjects operations (list/create/update/delete) fail due to a URL-casing mismatch between `subjectRouter.js` and every frontend call - see `01-overview.mdx` and `04-frontend-app.mdx`.
- Login issues a real JWT that's discarded client-side and never verified server-side on any other route - see `03-authentication.mdx`.
- Database credentials are hardcoded in `backend/config/db.js` rather than read from environment variables, unlike the rest of the app's configuration.
- No `backend/.env`/`.env.example` exists - `PORT` is undefined and `JWT_SECRET` falls back to a hardcoded default unless one is created.
- `student.js`'s and `subject.js`'s update/delete handlers don't check `affectedRows`, so acting on a nonexistent ID still returns a success response.
- `bcryptjs` is a listed backend dependency alongside `bcrypt`; only `bcrypt` is actually imported anywhere.

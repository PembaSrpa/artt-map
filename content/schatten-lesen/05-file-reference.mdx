## Notable gotcha files

- **`components/ConditionalScales.jsx` and `components/ConditionalScales.tsx` are duplicates** — identical logic, same exported function name, different file extensions, both present in the same directory. `app/layout.tsx` imports `'@/components/ConditionalScales'` with no extension; which file actually resolves depends on Next.js/webpack's configured module resolution extension order (TypeScript projects conventionally resolve `.tsx` before `.jsx`), but having both on disk is redundant and a future edit to one is easy to make without realizing the other exists.

  > ⚠️ Unclear: without inspecting the exact resolved Next.js/webpack module resolution order used for this project's build (not fully visible from `tsconfig.json`/`next.config.js` alone), it can't be stated with certainty which of the two files is actually bundled — only that both exist and are currently identical, so it doesn't affect current behavior either way.

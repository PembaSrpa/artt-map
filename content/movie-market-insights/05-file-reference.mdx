## Things worth double-checking if this workbook is edited further

- The `Primary_Genre`/`Primary_Company` extraction is text-splitting, not JSON parsing - it depends on the source file's exact JSON field ordering staying the same on any future refresh (see `02-data-source-and-transformations.mdx`).
- `chart2`'s bar chart and both treemaps reference fixed, separately-placed top-N ranges rather than their full underlying pivots - resizing a pivot won't automatically resize what these three charts show.
- The workbook's Power Query connections point at an external file, `tmdb_5000_movies.xlsx` - a "Refresh All" will fail or prompt for a new file location if that source file isn't available at its original path.

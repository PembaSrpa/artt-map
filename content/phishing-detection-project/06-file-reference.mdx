## Corrections and gaps worth double-checking

- `requirements.txt` is referenced by the README but doesn't exist in this repo - see `01-overview.mdx` for the inferred dependency list.
- The README calls the blacklist file `phishing.db`; the actual file/config name is `url_blacklist.db`.
- The README describes training as producing an XGBoost model specifically; `model.py` actually trains and compares three model types and saves whichever wins on test accuracy as `model.pkl` - see `05-model-training.mdx`.
- `web_traffic` (`featuresExt.py`) calls Alexa's discontinued ranking API and will always return `0` today - see `04-feature-extraction.mdx`.
- `check.html` references a `styles.css` file that doesn't exist anywhere in the project (no `static/` folder at all) - harmless since the page's real styling is inline, but worth cleaning up.
